# 📦 Supply Chain Routing Engine

## Business Problem
International export orders require specialized customs paperwork and routing logic compared to domestic shipments. This project automates the routing decision process for a UK-based e-commerce retailer.

## Architecture
- **Lab (Backend):** Cleaned 541k+ raw transactions, engineered features, and trained a Logistic Regression classification model using `scikit-learn` to predict shipping routes based on order quantity and unit price.
- **Factory (Frontend):** Built an interactive web application using `Streamlit` allowing logistics managers to input live order metrics and receive instant routing predictions.

## Tech Stack
Python, Pandas, Scikit-Learn, Joblib, Streamlit, Git
